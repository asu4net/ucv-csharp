# Create C# project

## Open the terminal

Open `windows search` and type `cmd`, thenk press `enter`. This should open a black terminal. 

## Check if .NET is intalled: 

- In your terminal type `dotnet --version`. This should print the version number if dotnet is installed.
- If it is **NOT** installed run `winget install Microsoft.DotNet.SDK.10`
- Close the terminal and reopen it.
- Repeat `dotnet --version `to check if it is succesfully installed.
