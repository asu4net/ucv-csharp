# Create C# project
--- 

0. Open `windows search` and type `cmd`, thenk press `enter`. This should open a black terminal. 
1. Check if .NET is intalled: 
    1.1 In your terminal type `dotnet --version`. This should print the version number if dotnet is installed.
    1.2 If it is **NOT** installed run `winget install Microsoft.DotNet.SDK.10`
    1.3 Close the terminal and reopen it.
    1.3 Repeat the *1.1* step to check if it is succesfully installed.
