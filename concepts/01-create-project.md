# Create C# project
--- 

0. Open `windows search` and type `cmd`, thenk press `enter`. This should open a black terminal. 
1. Check if .NET is intalled: 
    1. In your terminal type `dotnet --version`. This should print the version number if dotnet is installed.
    2. If it is **NOT** installed run `winget install Microsoft.DotNet.SDK.10`
    3. Close the terminal and reopen it.
    4. Repeat the *1.1* step to check if it is succesfully installed.
